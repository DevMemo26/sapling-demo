# Sapling Demo · Task Board

Proyecto mínimo (HTML + CSS + JS, sin dependencias) usado como campo de pruebas
para la **demostración en vivo de Sapling SCM** (Parte 2, punto 9):

- Gestión de **cambios apilados** (*stacked commits*).
- **Bifurcaciones paralelas** (bookmarks).
- Publicación de cambios a GitHub con `sl push`.

## Uso

Abre `index.html` en el navegador. Las tareas se guardan en `localStorage`.

## Flujo de la demo

Ver `GUIA-DEMO.md` para la secuencia exacta de comandos.
